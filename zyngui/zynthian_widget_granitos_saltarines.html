Granitos saltarines

A granular delay. The input is recorded into a 3 s buffer, and the sound comes back as many short grains read from it. Each grain can hop around the buffer like a bouncing ball, which gives the plugin its character.

Widget

The strip is the delay buffer, a ring of 3 s: the sound is recorded moving along it and wraps around at the end. The thin line is where the grains read by default, which is the delay time behind the recording point. Each dot is a grain that is sounding, drawn where it really is reading. The ball bounces above the strip all the time, and settles and is thrown again; when it is high and Hop is up, the grains jump toward the present. The bar under the strip shows how many grains sound at once.

Delay

  • Time: how far back in the buffer the grains start, in ms.
  • Feedback: how much of the output goes back into the buffer, so each repeat is heard again.
  • Mix: dry signal against the granular (wet) signal.
  • Stereo spread: how far each grain's random pan reaches from the centre: 0 keeps everything in the middle, 100 spreads the grains across the whole stereo field.

Grains

  • Grain size: length of each grain, in ms. Short grains sound grainy, long ones sound smooth.
  • Density: how many grains start per second.
  • Pitch: transposes the grains, in semitones.
  • Jitter: randomness of each grain's start position and pitch.

Hop

  • Hop: how far the grains follow the bouncing ball. While the ball is high, new grains start closer to the present, so the echoes jump with the ball. At 0 the ball still bounces but the grains ignore it. This is the main character control.
  • Gravity: how quickly the ball settles. Low values keep it bouncing for several seconds, high values settle it in about a second. You see it in the ball, and hear it when Hop is up.
  • Reverse: the chance that a grain plays backwards.
  • Freeze: stops recording new input, so the buffer keeps looping the same material and the grains keep hopping over it.

Tips

Raise Hop slowly from 0 to hear the echoes start to jump: high values can sound chaotic. Try a long grain size with low density for smooth, sustained textures, and short grains with high density for clouds.
