Granitos saltarines

A granular delay. The input is recorded into a 3 s buffer, and the sound comes back as many short grains read from it. Each grain can hop around the buffer like a bouncing ball, which gives the plugin its character.

Widget

The strip is the delay buffer, a ring of 3 s: the sound is recorded moving along it and wraps around at the end. The thin line is where the grains read by default, which is the delay time behind the recording point. Each dot is a grain that is sounding, drawn where it really is reading. The ball bounces above the strip: the higher it is, the bigger the current hop, and it stays down when Hop is 0. The bar under the strip shows how many grains sound at once.

Delay

  • Time: how far back in the buffer the grains start, in ms.
  • Feedback: how much of the output goes back into the buffer, so each repeat is heard again.
  • Mix: dry signal against the granular (wet) signal.
  • Stereo spread: how wide the grains are spread across the stereo field.

Grains

  • Grain size: length of each grain, in ms. Short grains sound grainy, long ones sound smooth.
  • Density: how many grains start per second.
  • Pitch: transposes the grains, in semitones.
  • Jitter: randomness of each grain's start, pitch and pan.

Hop

  • Hop: how far each grain bounces around the buffer. This is the main character control.
  • Gravity: how quickly the bounces die away. Low values keep the bouncing going, high values settle it fast.
  • Reverse: the chance that a grain plays backwards.
  • Freeze: stops recording new input, so the buffer keeps looping the same material and the grains keep hopping over it.

Tips

Start with Hop at 0 and raise it slowly: high values can sound chaotic. Try a long grain size with low density for smooth, sustained textures, and short grains with high density for clouds.
